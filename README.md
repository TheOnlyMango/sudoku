# Sudoku Game

A Sudoku game implemented in Python with both GUI and CLI interfaces, featuring puzzle generation, solving, and interactive gameplay.

## Features

- **Two Interfaces**: Play with a graphical window (GUI) or in the terminal (CLI)
- **Puzzle Generation**: Generate puzzles with four difficulty levels (Easy, Medium, Hard, Expert)
- **Interactive GUI**: Click cells to enter numbers with a beautiful, intuitive interface
- **Interactive CLI**: Play Sudoku directly in your terminal with a clean text interface
- **Solver**: Built-in backtracking solver to solve any valid Sudoku puzzle
- **Hints**: Get hints when you're stuck
- **Validation**: Real-time validation of moves according to Sudoku rules
- **Error Highlighting**: Display errors to help you find mistakes

## Installation

No external dependencies required! This project uses only Python standard library.

```bash
# Clone or download the repository
cd sudoku

# Python 3.7+ required
python3 --version
```

## Usage

### Playing the Game

**GUI Mode (Default):**

```bash
# Launch GUI - default mode
python3 main.py

# Or explicitly
python3 main.py --gui

# Or use the dedicated GUI launcher
python3 gui_main.py
```

**CLI Mode:**

```bash
python3 main.py --cli
```

### GUI Controls

In GUI mode:
- **Click a cell** to select it
- **Press 1-9** to enter a number
- **Press 0, Delete, or Backspace** to clear a cell
- **Use buttons** for game controls:
  - **New Game** - Start a new puzzle (select difficulty from dropdown)
  - **Clear Cell** - Clear the selected cell
  - **Hint** - Get a hint for an empty cell
  - **Check** - Verify if your solution is correct
  - **Show Errors** - Toggle error highlighting (wrong cells turn red)
  - **Solve** - Display the complete solution

Color coding:
- **Gray background** - Initial puzzle cells (cannot be modified)
- **Blue text** - Numbers you entered
- **Light blue background** - Currently selected cell
- **Red background/text** - Errors (when "Show Errors" is enabled)

### CLI Commands

Once in the game, you can use the following commands:

- `new [easy|medium|hard|expert]` - Start a new game with specified difficulty
- `show [errors]` - Display the current board (optionally highlight errors)
- `move <row> <col> <value>` - Place a number (row and col are 1-9)
- `clear <row> <col>` - Clear a cell
- `hint` - Get a hint for the next move
- `check` - Check if your current solution is correct
- `solve` - Display the solution
- `quit` - Exit the game

## How It Works

### Board Representation

The Sudoku board is represented as a 9x9 grid using a 2D list. Empty cells are represented by 0, and filled cells contain numbers 1-9.

### Solver Algorithm

The solver uses a backtracking algorithm:
1. Find an empty cell
2. Try numbers 1-9
3. For each valid number, place it and recursively solve
4. If recursion succeeds, puzzle is solved
5. If recursion fails, backtrack and try next number

### Puzzle Generation

Puzzles are generated by:
1. Creating a complete valid board (filling diagonal boxes, then solving)
2. Randomly removing numbers while ensuring unique solution
3. Number of removed cells determines difficulty level

## Hidden Chat Feature

The Sudoku game includes a hidden secure chat application for private communication over a Tailscale network. This feature is activated through a special sequence in the GUI.

### Activation

1. Launch the Sudoku GUI
2. Select **Expert** difficulty from the dropdown
3. Click the **ERR** button

This will prompt for a username and launch the chat interface.

### Chat Server

The chat server must be running on the main node before clients can connect.

**Start server on main-win (100.115.233.16):**

```bash
python3 chat_server.py
```

The server listens on port 7331 and provides:
- Real-time group messaging
- Direct messages between users
- Offline message storage (SQLite)
- User list tracking
- Connection/disconnection announcements

### Chat Features

- **90s Hacker/mIRC Aesthetic**: Dracula color scheme with terminal-style interface
- **User List**: Shows all connected users (left panel)
- **Group Chat**: Public messages visible to all (right panel)
- **Direct Messages**: Send private messages with `/msg username message`
- **Offline Messages**: Messages to offline users are stored and delivered on login
- **Color Coding**:
  - System messages: Orange
  - Usernames: Cyan
  - Direct messages: Pink
  - Regular text: Green

### Network Setup

The chat uses Tailscale IPs for secure communication:
- **Server**: main-win @ 100.115.233.16:7331
- **Clients**: Any Tailscale-connected device

All messages are transmitted over the encrypted Tailscale network.
